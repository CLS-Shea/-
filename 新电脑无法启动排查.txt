=====================================================================
  拷贝到新电脑后「双击一闪而过/没反应」排查手册
=====================================================================

【最快定位】第 1 步：用调试模式看报错
---------------------------------------------------------------------
1. 进入项目文件夹，双击：
       「枫云AI虚拟伙伴Web版(调试模式).bat」
2. 这次会弹出【黑色命令窗口】并显示具体错误（普通版用 pythonw
   无窗口，所以之前一闪而过看不到原因）。
3. 把黑色窗口里的【报错文字】记下来/拍照发给我，即可对症下药。

※ 如果连调试模式也一闪而过/提示"系统找不到文件"，跳到第 2 步。


【最常见原因】第 2 步：查杀毒软件有没有隔离文件
---------------------------------------------------------------------
U盘拷贝到新电脑时，Windows Defender / 360 / 火绒等常把
runtime 里的 python.exe、onnxruntime.dll、sherpa-onnx 的 dll、
PySide6 的 Qt 库误判为病毒【静默删除】，导致启动失败。

操作（以 Windows 自带的 Defender 为例）：
1. 开始菜单搜「Windows 安全中心」→ 打开
2. 点「病毒和威胁防护」→ 下方「保护历史记录」
3. 看有没有被隔离的项目，名称类似：
   - python.exe / pythonw.exe / python312.dll
   - onnxruntime.dll / sherpa-onnx 相关 .dll
   - Qt6*.dll / PySide6 相关
4. 如果有 → 点「操作」→「还原」（恢复被删文件）
5. 还原后，把项目文件夹加入【排除项】：
   「病毒和威胁防护」→「管理设置」→「排除项」→「添加排除项」
   → 选【文件夹】→ 选中整个项目文件夹
   → 以后就不会再误删了
6. 第三方杀软（360/火绒/腾讯电脑管家）同理：查隔离区 → 恢复 →
   把项目文件夹加入白名单/信任区。


【核对文件】第 3 步：确认拷贝完整
---------------------------------------------------------------------
确认下面这些【关键文件】都在项目文件夹里（一个都不能少）：
   runtime\python.exe
   runtime\pythonw.exe
   runtime\python312.dll
   runtime\Lib\site-packages\   （整个依赖库文件夹）
   dist\assets\                （前端+角色模型）
   data\                       （配置+模型）
   lib\                        （tk/tcl 库）

如果发现缺失，说明 U 盘拷贝不完整（中断/漏拷），需重新完整拷贝。
拷贝时建议：整个文件夹【复制→粘贴】，不要在拷贝过程中拔出U盘。


【其他可能】第 4 步：其他原因
---------------------------------------------------------------------
1. 磁盘空间不足？项目约 1.4GB，需保证 C 盘/目标盘有足够空间。
2. 项目放在中文/特殊字符路径？建议放在 D 盘根目录或英文路径下，
   避免个别组件对中文路径支持不佳。
3. 双击的是否是启动 .bat？如果双击的是 main.py 或其它文件，不会启动。
   应双击：
       - U盘便携版-启动(插电脑用).bat（推荐，全屏双角色）
       - 枫云AI虚拟伙伴Web版.bat（普通模式）
4. 首次启动若弹出防火墙提示，点「允许访问」（不影响启动，但影响
   局域网/电视访问）。
