=====================================================================
  阿里云百炼（通义千问）大模型接入说明
=====================================================================
已为你完成以下自动配置：

  【对话语言模型】  qwen-plus（均衡，语音交互友好）
  【图像识别VLM】   qwen-vl-plus
  【语音合成TTS】   cosyvoice-v1
  【API地址】       https://dashscope.aliyuncs.com/compatible-mode/v1

你只需要完成【第1步】获取 Key 和【第3步】填 Key 即可使用。
---------------------------------------------------------------------

第1步：获取阿里云百炼 API Key（一次性）
---------------------------------------------------------------------
1. 打开百炼控制台：https://bailian.console.aliyun.com/
2. 用阿里云账号登录（没有就先注册，并完成实名认证）
3. 首次使用需「开通百炼模型服务」（按页面提示操作，通常免费）
4. 进入左侧菜单【API-KEY】页面
5. 点击【创建 API-KEY】，复制生成的密钥（以 sk- 开头）
   ※ 请妥善保管，它就是你的 API 密钥


第2步：了解 Key 的填写位置（软件已留好占位）
---------------------------------------------------------------------
  A. 对话 + 图像识别 用同一个 Key：
     软件主界面 → 点击【⚙设置】→ 找到「自定义API-api_key」输入框
     → 粘贴你的阿里云 API Key

  B. 语音合成（CosyVoice）用同一个 Key：
     打开文件  data/set/custom_tts_set.txt
     把 [api_key] 下面那一行 改成你的 API Key
     把 [voice]  下面那一行 改成你想用的音色名（见第4步）


第3步：重启软件生效
---------------------------------------------------------------------
填好 Key 后，关闭软件重新打开（或用 大屏模式 启动脚本）。
软件已自动切换为：对话=自定义API-LLM / 语音=自定义API-TTS / 图像=自定义API-VLM


第4步：CosyVoice 音色选择（可选）
---------------------------------------------------------------------
打开 data/set/custom_tts_set.txt，把 [voice] 那行改成你喜欢的音色，常用：
  longxiaochun  龙小淳（女声，自然清晰，推荐）
  longxiaoxia   龙小夏（女声）
  longxiaozui   龙小嘴（女声）
  longshaoye    龙小帅（男声）
  longcheng     龙橙（男声）
  longjing      龙婧（女声）
  longquan      龙荃（男声）
  longshu       龙舒（男声）
  longyue       龙悦（女声）
示例：把 [voice] 行改成  longxiaochun  即为龙小淳女声。


第4.5步：填写【你自己设计的音色】（声音复刻/自定义音色）
---------------------------------------------------------------------
阿里云百炼支持"声音复刻"：把你提供的录音训练成专属音色，然后
在 [voice] 栏填这个音色的 ID 即可。

1. 打开百炼控制台：https://bailian.console.aliyun.com/
2. 左侧菜单找到【声音复刻】（部分版本叫"自定义音色"/"我的音色"，
   一般在"模型广场"或"管理"分类下；找不到可用站内搜索"声音复刻"）
3. 点击【创建音色】→ 上传你的音色样本（建议 10 秒~1 分钟、清晰无杂音
   的人声录音，wav 或 mp3 格式）
4. 提交后等待训练完成（一般几分钟），完成后该音色会显示一个【音色ID】
   （一串字母数字，不是 longxiaochun 这种预设名）
5. 把那个【音色ID】复制，粘贴到
      data/set/custom_tts_set.txt 的 [voice] 那一行
   （例如 [voice] 行写成  mbc-cosyvoice-v2-xxxxx 之类）
6. 若自定义音色需要 CosyVoice 2.0，请把同文件 [model] 行改成
      cosyvoice-v2

※ 注意：
  - 自定义音色与调用必须使用【同一个百炼账号、同一个地域】。
  - 声音复刻功能可能需要实名认证 / 开通 / 可能按量计费，以控制台提示为准。
  - 如果填了自定义音色 ID 后报错或无声音，优先检查 [model] 是否需改为
    cosyvoice-v2，以及音色 ID 是否复制完整。


第4.6步：【阿里云实时语音合成】（Qwen-TTS Realtime，推荐用于双角色）
---------------------------------------------------------------------
软件已内置【阿里云实时TTS】引擎（WebSocket 流式合成，首响延迟更低），
两个角色南小橙/程小鹭 已默认启用：
  - 南小橙 → 系统音色 Ethan（晨煦·阳光男声）
  - 程小鹭 → 系统音色 Serena（苏瑶·温柔小姐姐）
  切换角色会自动换对应音色（语音入口：roles.json 的「实时TTS音色」字段）。

1. 依赖已安装：dashscope>=1.25.11（已装 1.27.2），无需再操作。
2. 引擎切换：主界面【🔊语音合成引擎】选择【阿里云实时TTS】；
   或直接在 data/db/roles.json 里把角色 TTS引擎 改为「阿里云实时TTS」。
3. 音色修改：编辑 data/db/roles.json 的「实时TTS音色」字段，
   常用系统音色（实时模型 qwen3-tts-flash-realtime 支持）：
     Ethan    晨煦（阳光温暖男声）      Serena  苏瑶（温柔小姐姐）
     Cherry   芊悦（亲切小姐姐）        Chelsie 千雪（二次元女声）
     Moon     月白（率性男声）          Momo    茉兔（撒娇搞怪）
     Vivian   十三（可爱小暴躁）        Kai     凯（男声）
   完整音色表见：百炼文档《Qwen-TTS音色列表》。

※ 关于自定义音色的重要说明：
  - 你之前用的自定义音色 qwen-tts-vd-bailian-voice-... 是"声音设计"
    创建、绑定在【非实时 qwen-tts】模型上的；实时模型(qwen3-tts-vd-realtime)
    无法直接使用它（报 CLIENT_ERROR）。
  - 若要自定义音色走实时合成：请在百炼控制台【声音设计】重建音色，
    创建时把 target_model 选为 qwen3-tts-vd-realtime-2026-01-15，
    然后把新生成的音色ID 填入 roles.json 该角色的「实时TTS音色」字段。
  - 模型会自动按音色前缀选择：qwen-tts-vd-*→VD实时模型 / qwen-tts-vc-*→VC
    实时模型 / 其他(系统音色)→qwen3-tts-flash-realtime。也可随时把角色
    引擎切回「自定义API-TTS」使用旧的非实时自定义音色。


第5步：常见问题
---------------------------------------------------------------------
Q1: 提示「自定义API配置错误」/ 401 Invalid API-key？
  A: 说明 API Key 没填对，或 Key 的地域与地址不匹配。
     本软件地址是北京地域（dashscope.aliyuncs.com），请用【北京地域】
     创建的 API Key。

Q2: 提示 429 或欠费？
  A: 免费额度用尽或账户未开通，需在百炼控制台开通/充值。

Q3: 想要更快/更强的对话模型？
  A: 在设置里把「自定义API-LLM-model」改为：
       qwen-turbo（更快，延迟低）
       qwen-max  （能力最强，稍慢）
     （改完保存并重启）

Q4: 语音合成没声音？
  A: 确认 custom_tts_set.txt 的 [voice] 和 [api_key] 都填好了；
     确认网络可访问 dashscope（阿里云国内服务，一般无需代理）。


安全提醒
---------------------------------------------------------------------
- API Key 只保存在本地配置文件，软件不会把它发送给网页访问者。
- 不要将 data/set、data/db 文件夹分享给他人，以免密钥泄露。
