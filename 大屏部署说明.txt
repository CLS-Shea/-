=====================================================================
  枫云AI虚拟伙伴 - 大屏/电视部署说明（U盘便携版）
=====================================================================

一、部署前提
---------------------------------------------------------------------
1. 需要一台【主机】运行本软件（可以是：现有电脑 / Windows大屏一体机 /
   迷你主机(NUC/迷你PC) / 树莓派+Windows 等）。
2. 主机需 Windows 10/11（软件自带 Python 运行环境，无需安装任何依赖）。
3. U盘容量建议 4GB 以上（本项目约 1.4GB）。
4. 大屏/电视：只要能开浏览器即可（Windows大屏、Android电视/平板、
   普通电视接网络盒子等均可）。


二、快速上手（U盘即插即用）
---------------------------------------------------------------------
1. 把整个「AIv4.0」文件夹复制到U盘（保持文件夹结构不变）。
2. 把U盘插入主机，进入文件夹。
3. 选择一种启动方式（双击即可）：

   【大屏模式-网页全屏.bat】  推荐！跨设备通用
       - 启动网页服务，自动打开本机浏览器全屏访问聊天页面
       - 电视/平板/手机等设备在浏览器输入【主机IP:5260】即可互动
       - 3D角色页面：5261(Live2D) / 5262(MMD) / 5263(VRM)

   【大屏模式-桌面全屏.bat】  Windows 大屏一体机专用
       - 直接在主机屏幕上全屏运行桌面版界面（支持语音/打字）
       - 按 F11 或 Esc 可退出全屏

   【枫云AI虚拟伙伴Web版.bat】 普通模式（窗口模式，原样运行）


三、如何让电视/其他设备访问
---------------------------------------------------------------------
1. 确保主机和电视连接在【同一个局域网】（同一个WiFi/路由器）。
2. 在主机上查看本机IP：打开设置→网络，或运行 ipconfig 查看 IPv4 地址，
   例如 192.168.1.100。
3. 在电视的浏览器地址栏输入：
       http://192.168.1.100:5260
   （把 192.168.1.100 换成你主机的实际IP）
4. 电视浏览器一般有全屏功能：Edge/Chrome 按 F11，或用遥控器菜单找
   "全屏/影院模式"。建议把该网址加入浏览器书签/主屏幕。

   注意：
   - 如无法访问，请检查主机防火墙是否放行 5260~5263 端口
     （首次启动时会弹出防火墙提示，请勾选"允许访问"）。
   - 主机如果是笔记本，部分系统在连接WiFi时需开启"网络发现"。


四、功能说明（网页模式在大屏/电视上可用哪些功能）
---------------------------------------------------------------------
网页聊天页(5260)：
   - 打字对话（触摸屏可直接点击输入框）
   - 显示虚拟伙伴回复（文字）
3D角色页(5261/5262/5263)：
   - 全屏展示 Live2D / MMD / VRM 3D角色，会随语音播放张嘴

注意：语音识别/语音输出等【音频功能】只在【主机】上生效
  （大屏/电视通过网页访问时不支持音频输入输出，需在主机上用
   桌面版/网页版本机访问 127.0.0.1:5260）。
  如需在大屏上语音互动，请用【大屏模式-桌面全屏.bat】在主机大屏上运行。


五、AI对话联网说明
---------------------------------------------------------------------
- 软件支持在线(云端API)和离线(本地模型)两种方式，配置与电脑上完全一致。
- 在线方式：需要主机联网，并已配置好 API Key
  （data/set/cloud_ai_key_set.json 等配置文件）。
- 离线方式：可选用本地 Ollama / 本地 VITS 语音等，无需联网。
- 电视/大屏本身不需要联网（只需能访问主机局域网IP即可）。


六、API Key 安全性说明（重要）
---------------------------------------------------------------------
1. 所有 API Key 只保存在主机本地配置文件
   （data/set/cloud_ai_key_set.json、data/db/config.json），
   【不会】通过网络页面传输或显示给任何访问者。
2. 网页服务只向浏览器提供"聊天文本"和"角色页面资源"，密钥仅由后端
   调用云端API时使用，前端无法获取。
3. 局域网内其他人只能看到聊天内容，拿不到你的密钥。
   为更安全，建议：
   - 在主机上为系统设置开机密码
   - 不要将配置文件（data/set、data/db）通过任何方式外传
   - 如部署在公共场所，建议在路由器上限制可访问的IP范围


七、常见问题排查
---------------------------------------------------------------------
Q1: 双击bat后没有反应/一闪而过？
  A: 尝试双击【调试模式】的bat（枫云AI虚拟伙伴Web版(调试模式).bat），
     会显示报错信息，把错误截图发给我们。

Q2: 电视打不开网页？
  A: 1) 确认手机在同一个WiFi下先试试能否打开（手机浏览器访问主机IP:5260）；
     2) 检查主机防火墙是否放行端口；
     3) 确认主机IP没写错。

Q3: 网页打开但角色不显示？
  A: 3D角色需要浏览器支持 WebGL，较新的电视/设备一般支持；
     个别老旧电视盒子可能不支持，建议用手机/平板或支持WebGL的设备。

Q4: 想开机自动启动大屏模式？
  A: 把【大屏模式-网页全屏.bat】的快捷方式放到主机
     开机启动文件夹（Win+R 输入 shell:startup 回车即可打开）。

Q5: U盘在其他电脑上能用吗？
  A: 可以。项目自带 Python 运行环境，任何 Windows 10/11 电脑插上即用，
     无需安装任何东西。

Q6: 大屏桌面模式字太小/界面显示不全？
  A: 桌面全屏模式已自动放大字号与图标。若4K大屏仍显小，可在
     gui_sub.py 中把 _kiosk_fullscreen 分支的 scaling_factor 放大系数
     (1.3) 调大。
