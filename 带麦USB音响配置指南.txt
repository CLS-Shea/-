=====================================================================
  Y57M 带麦克风 USB 音响 - 配置与使用指南
  （在【新主机/使用这台音响的电脑】上操作）
=====================================================================

一、设备是什么、要不要装驱动
---------------------------------------------------------------------
- 这类 USB 带麦音响是【标准 USB 声卡】(USB Audio Class)：
  Windows / Linux / 树莓派 插入后会自动识别，即插即用。
- 【不需要】装额外驱动，也不需要厂商 SDK。任何程序（本项目、
  音乐播放器、录音机）都能通过系统音频接口直接调用它。
- 它插入后会显示成【两个】设备：
    · 扬声器部分  → 输出声音(语音合成/音乐)
    · 麦克风部分  → 输入声音(语音识别)


二、第一步：插入并确认系统识别
---------------------------------------------------------------------
1. 把 USB 音响插到电脑 USB 口（建议插机箱后置 USB）。
2. 右键任务栏【喇叭】图标 → 声音设置。
3. 应能看到：
   - 「输出」里出现类似 "USB PnP 音频设备 / USB Audio / 扬声器"
   - 「输入」里出现类似 "USB PnP 音频设备 / USB Audio / 麦克风"
4. 若【设备管理器】→「音频输入和输出」里能看到这两个设备 = 已识别成功。
   ※ 如果完全没出现 → 说明这台可能不是标准声卡(少见)，请看文末"特殊情况"。


三、第二步：设成默认【输出】（语音合成从这里出声）
---------------------------------------------------------------------
1. 右键任务栏【喇叭】→ 声音设置 → 输出。
2. 在「选择输出设备」下拉里选【USB 音响/扬声器】那个。
3. 点「测试」应能听到提示音 = 输出 OK。
（项目播放语音用 Windows 默认输出设备，设好它项目就自动用它发声）


四、第三步：设成默认【输入】（语音识别从这里收音）
---------------------------------------------------------------------
1. 同样在声音设置里往下到「输入」。
2. 在「选择输入设备」里选【USB 音响/麦克风】那个。
3. 点「测试」，对着麦克风说话，音量条应跳动 = 输入 OK。
4. 确认该麦克风【没被静音】、音量没拉到 0。


五、第四步：给软件指定麦克风编号（重要）
---------------------------------------------------------------------
项目用配置的「麦克风编号」收音。设了默认输入后一般也能用，
但为确保准确，用项目自带的诊断工具确认：

1. 双击项目根目录的「麦克风诊断工具.py」
2. 它会列出所有麦克风，并逐个测声，标出 ✅ 能录到声的是哪个
   （一般带 USB 字样的那个就是音响麦克风）
3. 记下那个设备编号（如 3）
4. 打开 data/set/more_set.json，把「麦克风编号」改成该编号：
       "麦克风编号": "3"
5. 重启软件生效。


六、麦克风权限（务必打开）
---------------------------------------------------------------------
Windows 设置 → 隐私和安全性 → 麦克风：
  · 「允许应用访问麦克风」→ 打开
  · 「允许桌面应用访问麦克风」→ 打开   ← 项目是桌面程序，靠这项
不打开的话：程序能“打开”麦克风但读到的是全静音(诊断工具会显示几乎静音)。


七、验证整条链路
---------------------------------------------------------------------
1. 打开系统「录音机」说话 → 能回放自己的声音 = 硬件+输入 OK。
2. 启动项目，让角色说话 → 应从 USB 音响出声 = 输出 OK。
3. 项目里用语音对话 → 能识别你说的话 = 完整 OK。


特殊情况（非标准设备，概率低）
---------------------------------------------------------------------
若插上后 Windows 完全没识别出音频设备，或设备管理器里有黄色感叹号：
1. 看商品包装/详情页是否附带「驱动/资料下载」(网盘链接)；
2. 很多这类产品实为【标准声卡】，请确认是否插紧、换 USB 口/USB线；
3. 若确实带主控需特定 SDK，把商品附带的说明/资料发我，我再帮你接入。
